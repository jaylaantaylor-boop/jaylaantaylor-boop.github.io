# jaylaantaylor-boop.github.io

The front door. `jaylaantaylor-boop.github.io` with nothing after it opens the
Owner Dashboard.

**The repo name has to be exactly `jaylaantaylor-boop.github.io`.** That is what
makes GitHub serve it at the bare address instead of under a path. Any other
name and it becomes an ordinary project page.

It holds no list of apps on purpose. The Dashboard is the one place that knows
about all four businesses, and a second list here would quietly drift out of
step with it. This page only forwards.

**If the Dashboard ever moves or is renamed**, change the address in three
places in `index.html` — the `canonical` link, the `refresh` meta, and the
`location.replace` line — and every address anybody has written down still
works.

Nothing else here needs touching. The four business apps and the others keep
their own addresses and are unaffected.
